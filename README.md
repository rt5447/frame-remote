# Frame Remote

A phone remote for a Samsung The Frame TV. It's a single web page that talks to the TV directly over your home Wi-Fi, with no computer or app needed.

**Open:** https://rt5447.github.io/frame-remote/

## First-time setup on a phone
1. Phone and TV on the same Wi-Fi.
2. Open `https://192.168.1.34:8002/api/v2/` in the phone's browser and accept the certificate warning (iPhone: **Show Details → visit this website**; Android: **Advanced → Proceed**).
3. Open the remote link above and choose **Allow** on the TV when it asks about "Phone Remote".
4. Add the page to your home screen.

To use a different TV address, tap the gear icon in the remote.
